# 🧭 Jenkins Pipeline — Report & Artifact Locations Guide

## 🏗️ 1️⃣ Target Folder — Maven Build Artifacts

📂 **Location on Jenkins Server:**
```bash
/var/lib/jenkins/workspace/Mega-Project/target/
```

⚙️ **What’s inside:**
```bash
bankapp-0.0.1-SNAPSHOT.jar
bankapp-0.0.1-SNAPSHOT.pom
```

💡 **Created by:**
```bash
mvn package
```

### 🧑‍💻 CLI Check
```bash
cd /var/lib/jenkins/workspace/Mega-Project/target
ls -lh
jar tf bankapp-0.0.1-SNAPSHOT.jar | head
```

### 🖥️ Jenkins UI Check
1. Go to **Mega-Project** in Jenkins.  
2. Click the latest build number (e.g., **#42**).  
3. Scroll to **“Last Successful Artifacts”** → click to download `.jar` or `.pom`.

## 🔍 2️⃣ Trivy FS Scan Report

📂 **Location on Jenkins Server:**
```bash
/var/lib/jenkins/workspace/Mega-Project/fs-report.html
```

🧾 **Generated by:**
```bash
trivy fs --cache-dir /var/lib/jenkins/trivy-cache --format table -o fs-report.html .
```

### 🧑‍💻 CLI Check
```bash
cd /var/lib/jenkins/workspace/Mega-Project
ls -lh fs-report.html
head -30 fs-report.html
grep -A 5 "CRITICAL" fs-report.html
```

### 🖥️ Jenkins UI Check
1. Open the latest **Mega-Project** build.  
2. Scroll to **Artifacts → fs-report.html** → click to view or download.  
3. *(Optional)* If using **HTML Publisher Plugin**, view under **“Trivy FS Scan Report”** tab.

🧩 **HTML Publisher Snippet:**
```groovy
post {
    always {
        publishHTML([reportDir: '.', reportFiles: 'fs-report.html', reportName: 'Trivy FS Scan Report'])
    }
}
```

## 🧠 3️⃣ SonarQube Quality Gate Report

📊 **SonarQube Dashboard:**
```
http://<sonar-server>:9000/projects
```

### 🧑‍💻 CLI Check
```bash
cat /var/lib/jenkins/jobs/Mega-Project/builds/<build_number>/log | grep "Quality Gate"
```

✅ **Expected Output:**
```
Quality Gate status: PASSED
```
or
```
Quality Gate status: FAILED
```

### 🖥️ Jenkins / Sonar UI Check
1. Open Jenkins build log to see “Quality Gate” line.  
2. Go to **SonarQube → Projects → [Your Project] (e.g., gcbank)**  
3. Review:
   - ✅ **Quality Gate Status**
   - 🧩 **Bugs**, **Vulnerabilities**, **Code Smells**
   - 📈 **Coverage**, **Duplications**

🔗 **Connected via Jenkinsfile:**
```groovy
withSonarQubeEnv('sonar')
waitForQualityGate abortPipeline: false, credentialsId: 'sonar-cred'
```

## 💡 Pro Tips
- Archive your reports automatically:
```groovy
post {
    always {
        archiveArtifacts artifacts: 'fs-report.html, target/*.jar', fingerprint: true
        publishHTML([reportDir: '.', reportFiles: 'fs-report.html', reportName: 'Trivy FS Scan Report'])
    }
}
```

- To list all Jenkins workspaces:
```bash
ls /var/lib/jenkins/workspace/
```
